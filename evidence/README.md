# evidence/

Drop your certificates, screenshots and project files in here, then list each one
in the `evidence` section of `data.js` (one level up).

- Images (png, jpg, gif, webp, svg) show as pictures on the Evidence page.
- Anything else (pdf, zip…) shows as a card with an "Open file" link.
- Keep filenames simple: lowercase, no spaces — `cs50-certificate.pdf`, `week3-check50.png`.
